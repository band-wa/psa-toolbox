## 一、一句话概括

在原工具箱的基础上**新增「按键映射」「应用管理」两个页面**，并把按键映射的注入载荷并入工具箱自己的 `修复PSA工具箱`（`ModApk`）链路，使得一次「修复核心组件」就能同时装上工具箱原有的音乐/地图补丁和我们新增的按键映射补丁。

## 四、主要修改（不是新增，是改上游已有的）

- **`app/src/main/assets/modapk/com.cusc.misc/config.json`**：6 条 operation → 11 条。原音乐/地图/`isBcallRunning` 三条一字未动，新增 KeyEventEmitter 4 条 + CarPropertyManager 1 + Data4gImpl 1 + BootReceiver 2。
- **`core/.../util/apktools/SmaliMod.kt`**：新增 `insertBeforeMethod` / `insertAfterRegisters` / `appendToClass` 三个方法。原有的 `DexInjector` 只能做 INVOKE_STATIC/IGET/SGET/CONST_STRING，表达不了「早退分支」。
- **`service/.../install/ModApk.kt`**：`applyModifications` 支持 `skipIfContains` 幂等键与三种新 type。
- **`service/.../service/PSAToolBoxService.kt`**：**删掉**音乐键(`"11"`)/地图键(`"13"`)长按的旧实现（走的 MCU 属性 `0x2141F04B` 通道），改由注入层统一接管，避免长按被启动两次。
- **`service/.../receiver/BootReceiver.kt`**：新增「不进界面（后台唤醒）」分支（`BootWake`），开机拉 APP 时可选不弹界面；清理动作从 `delay(10000)` 之后提前到 `user.sh` 之后立刻跑。
- **`ui/.../ui/Glassmorphism.kt`**：把大面积阴影拆成独立静态层。原来 `Modifier.shadow(8.dp)` 画在整页滚动容器上，内部任何变化都让该层失效，是滑动掉帧的主因。
- **`ui/.../component/ScrollableTabs.kt`**：Tab 加 group 分组、去逐项 alpha 动画、高度压到 44dp、去掉写死的 240dp 宽度。
- **`app/.../MainActivity.kt`**：Tab 顺序改为 系统设置 / 个性设置 / 音乐助手 / 导航助手 / 按键映射 / 仪表投屏 ‖ 油耗账本 ‖ 应用管理 / 维护诊断 / 专家模式 ‖ 关于软件。
- **`about/AboutSettingsRoute.kt`**：恢复上游的赞赏码、贡献者头像、版权行与「特别感谢」（GPL-3.0 §5 要求保留），并加「基于原版修改」说明与「GPL-3.0 许可证」按钮。
- **`hook/.../Hook.java`**：`VERSION` `"4"` → `"5"`。

## 五、在线更新（机制未改动，本 PR 不含分发文件）

检查更新、公告栏、Hicar/CarLife 修复包都通过 `psa.otaBase` / `psa.infoBase` 两个构建期属性指向外部静态托管，
**代码里没有任何硬编码地址**。本 PR 不含 `ota/` 目录与任何二进制分发件，托管在哪里由部署方自行决定：

```properties
psa.otaBase=https://raw.githubusercontent.com/<用户名>/<仓库名>/main/ota
psa.infoBase=https://raw.githubusercontent.com/<用户名>/<仓库名>/main/ota
```

不配置时行为与现在完全一致：检查更新提示「未配置远程下载服务」、公告显示「暂无新公告」、沙发管家提示未配置。
各文件的格式：`*_version` 一行版本号（与目标包的 `versionName` 完全相等才算最新）、`*_md5` 一行小写 hex。

## 六、没有做的事（如实记录）

- **实体空调键（风量/温度/AC）没有统一到注入载荷**。它们走的是 MCU 属性 `0x2141F04B` 通道，`com.cusc.misc` 侧**完全不注册**这个属性，事件根本收不到；要统一得让 misc 也注册该属性或改走 HVAC 属性直写，工作量大且未经实车验证，暂时仍归工具箱 `PSAToolBoxService`。
- **`tools/` 下三个修复包（HiCar / CarLife / 多媒体插件）本体为空**。这两条链路要的是「已经修好」的原厂改版包，请在车机上 `adb pull` 对应包后自行托管，并把 `*_version` 写成目标包自己的 `versionName`。
- **沙发管家（应用市场）的下载地址没有配**（`psa.shafaEndpoint`），按钮已在界面上隐藏（`SHOW_INSTALL_MARKET = false`），链路代码保留。
